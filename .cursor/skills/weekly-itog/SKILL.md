## Ежедневный отчёт на правку

**Пн–пт в 16:30 по Москве** (сб и вс — тишина, скрипт сразу выходит):

- Собирается **тот же набор данных, что у недели, но за текущие сутки**.
- Файл: `Рабочий стол\Ежедневные отчёты\на_правку\Ежедневный_отчёт_ГГГГ-ММ-ДД.docx`
- Word открывается, если пользователь вошёл в систему.

**08:30 пн–пт — догон предыдущего рабочего дня** (в понедельник — **пятница**, не сб/вс):

- файла нет → создать отчёт за тот день, открыть Word;
- файл есть, но не правили (открыли Word и закрыли без Save — не считается) → **снова открыть Word**;
- уже правили: папка `принятые` ИЛИ mtime файла > времени создания/генерации на 60+ сек → ничего не делать.

Дневные файлы за субботу и воскресенье **не создавать**. Недельный итог — только **пн–пт**.

Задачи планировщика создаёт сам `weekly_report.py` / `ensure_windows_daily_tasks` при любом запуске (`schtasks /Create /F`). Не просить щёлкать «Включить …bat». В выходной задача может сработать — скрипт выходит без отчёта.

**Если выключены и пятничный 16:30, и понедельник 08:30 — отчёт за пятницу сам не создаётся.**

### После правки пользователя (обязательно)

Пользователь правит Word и **сохраняет** (тот же файл) или кладёт копию в `принятые\`.

**Запрещено будущим агентам** для файлов в `Ежедневные отчёты` (и `на_правку`, и `принятые`):

- `--format`, DocAgent «Оформить документ», спеллер, замены канцелярита, перенумерация
- «улучшать» принятый дневной текст

Метка в файле: `НЕ ОФОРМЛЯТЬ ПОВТОРНО`. Код: `is_protected_daily_report` / `process_weekly_itog_document` сразу выходит.

Неделя `--from-daily`: приоритет `принятые`, иначе `на_правку`; дни без файла — пометка пропуска; сырой черновик только с `--fill-missing`. Тексты дней копируются **как есть**.

Ручной `Сделать еженедельный итог.bat` без `--from-daily` **не ломать** — это прежний полный сбор недели.

## Правила оформления (только первичная генерация и недельный скан)

Инструкция по делопроизводству 2025 (Минюст РБ № 65):

- А4, поля 30 / 8 / 20 / 20 мм
- Times New Roman 14 pt
- текст по ширине, абзацный отступ 1,25 см
- одинарный интервал тела; перед/после абзаца 0 pt
- номера страниц со 2-й, верх по центру, TNR 14 не жирный
- заголовки разделов («1. …») — прописными по центру

**Не** ставить нумерацию ДИ САТП 1.8 / 1.9.

**Пробелы:** двойные/тройные → один; неразрывный `\u00a0` → обычный пробел; табы в теле → пробел. Validate ловит два пробела подряд. Скобки: `текст ( выполнение )` → `текст (выполнение)` (пробел перед `(` после слова оставить).

**Интервал:** одинарный (1.0) на теле и заголовках; `space_before`/`space_after` = 0. Это то же общее правило, что у делопроизводителя.

**Маркеры списка запрещены:** не оставлять • /  / ○ / ■ / дефис-списки / bullet Word. Только нумерованные пункты или обычный текст. Не путать с номерами страниц и табуляцией подписи.
