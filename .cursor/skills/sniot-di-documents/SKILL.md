# Документы СНиОТ — Агент (правка) + ОБМЕН (образец)

## ГЛАВНОЕ ПРАВИЛО

См. `.cursor/rules/sniot-user-folder-only.mdc`.

### Правка — только папка Агент

```
N:\9 - Служба надёжности и охраны труда (СНiОТ)\Дубовик В.В\Агент\
```

Файлы пользователя:

- `ПРОЕКТ Старший мастер_оформлен.docx`
- `ПРОЕКТ Старший мастер_оформлен+.docx`

### Образцы — ОБМЕН read-only

Из `!!!ОБМЕН\РАССМОТРЕНИЕ  ДИ, РИ, ПОЛОЖЕНИЙ\` можно **читать** конкретный эталон для сравнения.  
**Нельзя:** править, сохранять, открывать соседние файлы, пакетно сканировать.

## Путь на правку

1. Поле **«1. Документ»** — файл в Агент
2. `handoff/request_latest.json` → `source_path` — только Агент

**Запрещено:** править docx в чате, править файлы в ОБМЕН/САТП.

## Запуск

```bash
python C:\Users\v.dubovik\AttestationSync\fix_sniot_document.py
```

## API

- `--target путь.docx` — файл **в папке Агент**
- `--check` — только проверка
- `assert_path_writable(path)` — guard перед записью

## Коды выхода

| Код | Значение |
|-----|----------|
| 0 | OK |
| 1 | Остались ошибки |
| 2 | Файл открыт в Word |
| 3 | Файл не найден |

## Межстрочный интервал (подписанты)

- **Блок «Разработал:» / «Согласовано:»** — межстрочный интервал **1,5** на каждом непустом абзаце от «Разработал:» до последней подписи.
- **Тело документа** — **не** 1,5; скрипт не меняет интервал пунктов 1.4.1., 2.2.1. и т.д.
- **Пустые строки:** по одной **перед** «Разработал:» и «Согласовано:»; **без** пустых строк **после** этих слов.
- Функции: `apply_signatory_line_spacing`, `validate_signatory_line_spacing` в `fix_sniot_document.py`.

## Конец документа (последние 2 страницы)

**Шаг 1 (всегда):** `fix_last_pages_and_signatories(doc, mode='natural')` — снять разрывы/keep, оформить подписантов, проверить хвост.

**Шаг 2 (только если оторваны):** `fix_last_pages_page_breaks(doc)` или флаг `--fix-page-breaks` — перенос абзаца/главы 5; **никогда** разрыв только перед «Разработал:».

Проверка: `validate_last_two_pages_layout(doc)`; эвристика сирот: `signatories_appear_orphaned(doc)`.
