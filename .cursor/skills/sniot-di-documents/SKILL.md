# Документы СНиОТ — правка в Агент/Проекты; образец только в Агент

## ГЛАВНОЕ ПРАВИЛО

См. `.cursor/rules/sniot-user-folder-only.mdc`.

### Правка — папка Агент или Проекты

```
N:\9 - Служба надёжности и охраны труда (СНiОТ)\Дубовик В.В\Агент\
N:\9 - Служба надёжности и охраны труда (СНиОТ)\Дубовик В.В\Проекты\
```

На диске папка называется **«Проекты»**. Результат `_оформлен.docx` сохраняется **рядом с исходником**.

Файлы пользователя по умолчанию (Агент):

- `ПРОЕКТ Старший мастер_оформлен.docx`
- `ПРОЕКТ Старший мастер_оформлен+.docx`

### Образец — только Агент + «образец» в имени (и для делопроизводителя)

Эталон оформления — файлы из папки Агент, в названии есть слово **«образец»** (например `ПРОЕКТ Старший мастер_образец.docx`).  
**Нельзя:** брать образец из ОБМЕН / САТП / Проекты / сети; пункт «Стандарт» не подтягивает чужой путь.  
Нет такого файла — оформлять по Инструкции по делопроизводству 2025 **без** эталона docx.

**Пробелы:** во всех документах делопроизводителя не больше одного пробела подряд; nbsp → обычный пробел; validate ловит остаток. Титул тоже сжать; Tab у подписантов не ломать.

**Интервал (все агенты):** межстрочный одинарный (1.0); перед/после абзаца тела 0 pt. Подписанты «Разработал:» / «Согласовано:» — 1,5. Заголовки глав без `space_after`.

**Маркеры списка запрещены (все агенты):** в оформленном документе не оставлять •, , ○, ■, дефис-списки `-`, автосписок Word (bullet). Только нумерованные пункты (1.1., 2.2.1.) или обычный текст. Не путать с номерами страниц, «1.4.1.» и табуляцией подписантов. Скрипт: `remove_list_markers_in_body`, `validate_list_markers`.

**.doc / .rtf** перед оформлением конвертируются во **временный** docx в TEMP (не писать `_converted` в папку Агент). Исходный `.doc` не перезаписывать.

**Не путать пути:** `N:/…` и `N:\…` — один файл; не копировать сам на себя.  
**Имя «ДИ …»** — должностная инструкция, не положение. `_оформлен` не образец.

## API

- `--target путь.docx` — файл **в папке Агент или Проекты**
- `--check` — только проверка
- `assert_path_writable(path)` — guard перед записью (Агент/Проекты)
- В конце `process_sniot_document` всегда `apply_mandatory_layout_fixes` (пробелы, номера, титул, сироты глав, даты подписантов, должность+ФИО одна строка, поля 30/10/20/20, маркеры списка, интервал 1.0, таблицы без firstLine, подписанты 1,5, keepNext блока с текстом, **пунктуация всего документа**). ДИ ОМТС — не схема САТП 1.8/1.9. N: и UNC — один каталог; Агент и Проекты — зоны записи.
- **Язык после правки (обязательно):** пунктуация XML → запись → Word орфография/грамматика (`apply_word_grammar_check`) → спеллер DocAgent (`russian_check`) для всех типов, включая ДИ. Кнопка XML вызывает `--skip-word`, чтобы таймаут Word не убил запись; грамматика Word — **следующим** вызовом, не внутри того же процесса.

## Нумерация ДИ

**Не удалять нумерацию исходника** (текст или список Word ListString) — только починить ошибки (`.5.1.1.`, двойной numPr+текст, шрифт) и сверить набор номеров в финале.  
**Запрещено** навязывать схему САТП 1.8/1.9 чужой ДИ, снимать 1.1–1.7, менять 2.x, вписывать номера, которых не было в исходнике. Если нумерация исходника целая — не трогать.

**Не менять формулировки исходника через text_edits.** Для ДИ выключены сравнение файлов и дописывание кодов ТКП (сдвиг нумерации). Проверка русского языка **включена для всех документов** (ДИ, РИ, положения, инструкции, еженедельный итог); **аббревиатуры спеллер не правят** (ЛСиМ, СНиОТ, САТП, ТКП, НПА, ЛПА и др.). Первое «ЛПА» без расшифровки оформляет `expand_first_lpa_abbreviation`, не спеллер. `process()` по-прежнему не вызывает `apply_russian_phrase_rules`. Только оформление + проверка русского без правки аббревиатур спеллером: поля, шрифт, отступы, интервал, титул, подписанты, нумерация как в исходнике.

**Не выделять** исправленные номера и чужие фрагменты: снять highlight/shading.

**Таблица подписантов** в исходнике → блок без таблицы: «Разработал:», должность+ФИО (Tab), пустая, «Согласовано:», согласующие. Таблицу согласования после переноса убрать.

## Нумерация ДИ САТП (старший мастер)

Глава 1 как на экране Word в образце: **1.1.–1.7.** вводные, затем **1.8.** руководствуется / **1.9.** должен знать.  
**Запрещено** ставить повторные «1.4.» / «1.5.» на эти разделы — это откатывает принятые исправления.  
Пункты: **1.8.1.–1.8.n**, **1.9.1.–1.9.n**. Вводный «1.4. Назначение…» не трогать.

В начале прохода — **принять правки рецензирования Word** (`accept_tracked_changes`). Иначе «не приняты предыдущие правки» и точка перед `.5.1.1.` из вставки «.».

## Инструкция по делопроизводству 2025

Норматив: Минюст РБ, утв. 29.08.2025 № 65. Автоматизировано в `fix_sniot_document.py`:

- поля А4 (30/10/20/20 мм; Минюст №65 п.18 — правое ≥8 мм, **для СНиОТ этого агента правое 10 мм**) — `apply_page_setup_deloproizvodstvo`
- одинарный интервал тела — `apply_body_single_line_spacing`
- TNR 14, по ширине, отступ 12,5 мм, номера стр. сверху TNR 14 не жирные — см. `sniot-di-documents.mdc`
- Титул на 1-й странице (nextPage), глава 1 со 2-й
- **Названия глав** (`1 ОБЩИЕ ПОЛОЖЕНИЯ`, `2 ДОЛЖНОСТНЫЕ ОБЯЗАННОСТИ`) — **по центру**, без отступа. Пользователь называет их «заголовки разделов». Это **не** строки `1.9. … должен знать:` / `2.1. …` (те — тело, отступ 1,25 см). `center_chapter_headers`, `apply_header_paragraph_format`.
- **Титул (константы `TITLE_*` в скрипте, не путь ОБМЕН):** шапка по центру; таблица **2 колонки** без рамок — ширины **4967/5212**, таблица **10179**; слева название + подчёркнутая линия + «номер инструкции» **12 pt**; справа «УТВЕРЖДАЮ» не жирный, должность, линия+пробел+И.О.Ф. **без Tab** во 2-м столбце, плашка даты **без таба** `keepLines`. **Если в исходнике таблицы нет**, а название и «УТВЕРЖДАЮ» — отдельные абзацы, **собрать** их в эту таблицу (`_ensure_title_left_right_stamp`); корректную таблицу не ломать. **После шапки** (в т.ч. ««МИНСККОММУНТЕПЛОСЕТЬ»») перед таблицей грифа — **6–8 пустых строк** (цель 6). **После таблицы перед «МИНСК YYYY» — пустые строки** (`TITLE_EMPTY_AFTER_STAMP_BEFORE_CITY = 1`), **без разрыва**. «МИНСК YYYY» внизу 1-й **в теле** (`framePr` `vAnchor=margin`), **не в колонтитуле**; сразу после города — `nextPage` **без vanish**, глава 1 с **верха** стр. 2 **без пустых строк**. `format_title_block` → `_ensure_title_left_right_stamp`, `ensure_title_stamp_gap_after_header`, `place_title_city_year_at_bottom`, `_clear_breaks_between_stamp_table_and_city`, `ensure_section_break_after_city_year`. Образец кнопки — только Агент + «образец».
- **Текст ДИ (указание пользователя, не text_edits ТКП):** в перечень «… должен знать:» добавить `основы делопроизводства`, если нет; пунктуация перечисления **всегда проверяется**: промежуточные `;`, последний `.` (пример: `1.9.15. коллективный договор;` / `1.9.16. основы делопроизводства.`). Оборот «исполняет, по распоряжению …, специалист» — запятые. Первое «ЛПА» без расшифровки → `локальным правовым актом (далее - ЛПА)` (падеж/число по контексту); повторные «ЛПА» не расшифровывать. `ensure_deloproizvodstvo_in_must_know`, `normalize_must_know_list_punctuation`, `fix_duty_by_order_commas`, `expand_first_lpa_abbreviation`.
- **После любой правки — пунктуация всего документа** (титул, тело, таблицы, подписанты) **и** перечислений «должен знать». Без этой проверки документ не «Готово». `check_document_punctuation_after_edit`, `validate_document_punctuation`.
- Номера пунктов (1.1., 2.2.1.) тем же шрифтом, что текст: TNR 14 не жирный

## Межстрочный интервал (подписанты)

- **Блок «Разработал:» / «Согласовано:»** — межстрочный интервал **1,5** на каждом непустом абзаце от «Разработал:» до последней подписи.
- **«Согласовано:»** — с двоеточием, не жирным.
- **Пустые строки:** по одной **перед** «Разработал:» и «Согласовано:»; **без** пустых строк **после** этих слов; без лишних переносов в блоке.
- Должность↔ФИО через **Tab только на одной строке**. **ФИО не переносить** (`keepLines`, короче линия, неразрывные пробелы в И.О.Ф.).
- Плашка даты: **новая строка**, короткий подчерк, `keepLines`, **без переноса**.
- **Отступ даты ровно с началом ФИО** (позиция таба = таб строки должности). На титуле дата **без таба**.
- Блок подписантов **не рвать и не отрывать от текста**: `keepNext` от хвоста тела до конца блока; **без пустых строк между согласующими**. `keep_signatory_block_with_text`, `compact_extra_empty_lines_in_signatory_block`.
- Если в исходнике **нет** «Разработал:» и **нет** строки И.О.Фамилия — вставить **одну строку** «Разработал:» + таб 12 см + жёлтый маркер `КТО???` (`keepLines`, без переноса). Существующие подписанты не менять. `ensure_missing_developer_block`.
- Функции: `apply_signatory_line_spacing`, `validate_signatory_line_spacing`, `apply_signatory_fio_one_line`, `fix_signatory_date_plaques`, `validate_signatory_date_plaques`, `validate_signatory_fio_one_line`, `compact_extra_empty_lines_in_signatory_block`, `ensure_missing_developer_block` в `fix_sniot_document.py`.

## Лишние символы

`strip_unnecessary_characters` / `sanitize_paragraph_text` — убирает invisible, nbsp, табы (не у подписантов), **двойные пробелы**, латинскую o/i в «Согласовано»/«СНиОТ», `,,`/`..`, пробел перед `.`, кавычки «»; нумерация `.1.4.1.` / `1.4.1..`; **ведущие маркеры списка** •  ○ ■ дефис; пробелы **внутри** скобок: `продукции ( выполнение )` → `продукции (выполнение)` (пробел перед «(» после слова оставить). Ведущие пробелы перед `1.1.` и лишний пробел после номера — убрать (`normalize_item_number_spacing`). Соседние дубли слов «службы службы» — схлопнуть. Титул: сжать двойные пробелы. Проверка: `validate_unnecessary_characters`, `validate_document_punctuation`, `validate_list_markers`. После любой правки обязателен повторный проход по **всему** документу (`check_document_punctuation_after_edit`).

## Интервал (все агенты)

Тело и заголовки глав: межстрочный **1.0**, `space_before`/`space_after` = **0**. Подписанты: **1,5**. `apply_body_single_line_spacing` / `validate_body_line_spacing`.

## Таблицы

**Первые три строки таблицы всегда вместе** — верхняя строка не остаётся одна внизу страницы. Остальные строки можно переносить. Таблица короче трёх строк — все строки вместе. Не ставить разрыв страницы между заголовком главы и таблицей сразу под ним.

**В ячейках таблиц отступов нет** — абзацный отступ первой строки (1,25 см) в таблицах не ставится и снимается, если уже был. В теле документа вне таблиц отступ 1,25 см остаётся.

Функции: `keep_table_header_rows_together`, `validate_table_header_rows_together`, `apply_table_paragraph_no_indent`, `validate_table_paragraph_indents`.

## Конец документа (последние 2 страницы)

**Шаг 1 (всегда):** `fix_last_pages_and_signatories(doc, mode='natural')` — снять разрывы/keep, оформить подписантов, проверить хвост.

**Шаг 2 (только если оторваны):** `fix_last_pages_page_breaks(doc)` или флаг `--fix-page-breaks` — перенос абзаца/главы 5; **никогда** разрыв только перед «Разработал:». Предпоследняя **может** содержать подписантов вместе с хвостом текста — принудительный разрыв не ставить, если блок туда помещается. Лист ознакомления — всегда отдельная страница (`ensure_acquaintance_sheet_separate_page`), в том числе фраза «С должностной инструкцией … ознакомлен». Чужая должность на листе — красная заливка заголовка.

## Обязательная проверка перед записью (без исключений)

1. После правки — **перечитать весь docx с диска** (`reload_document_from_path`).
2. Прогнать **все** правила (`validate_full_document_on_disk` → `validate_sniot_document`).
3. После любой правки проверить **пунктуацию всего документа** (`check_document_punctuation_after_edit`, `validate_document_punctuation`). Без этой проверки документ не «Готово».
4. **0 замечаний** — только тогда запись в папку Агент; после записи — повторная проверка файла на диске.
5. **Есть замечания** — **не перезаписывать** `_оформлен.docx`; показать список в окне «Готово».
6. **Word:** после XML тихо открыть документ. Красная черта = орфография: заменить по `GetSpellingSuggestions`, кроме аббревиатур (`apply_word_grammar_via_com`). Затем страница хвоста и «Разработал:». Если подписанты оторваны — перенос и повтор. Нет Word — предупреждение (`inspect_signatory_pages_via_word`).

См. `.cursor/rules/sniot-di-documents.mdc`, правило 34 в `fix_sniot_document.py`.

Проверка: `validate_last_two_pages_layout(doc)`; эвристика сирот: `signatories_appear_orphaned(doc)`.
