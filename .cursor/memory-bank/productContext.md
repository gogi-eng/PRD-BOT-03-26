## Документы СНиОТ (Word) — пути (28.08.2026)

**Исходник и образец** — любой файл, который пользователь открыл или указал (Загрузки, Рабочий стол, ОБМЕН, САТП, Агент, Проекты, флешка). Не отклонять из‑за папки. Не сканировать весь `N:\`.

**Запись** — поле «Результат». Предупреждение при ОБМЕН/САТП, без блокировки после подтверждения. Если поле пусто: рядом с исходником, иначе Проекты, иначе Агент.

**Оформление (все агенты):** не больше одного пробела подряд; межстрочный одинарный (1.0); перед/после абзаца тела 0 pt; подписанты «Разработал:»/«Согласовано:» — 1,5; **маркеры списка запрещены** (•, , ○, ■, дефис-списки, bullet Word) — только нумерованные пункты или обычный текст.

Правило: `.cursor/rules/sniot-user-folder-only.mdc`.
