## Хронология (кратко)

1. Пользователь: не может подключиться к серверу, «пароль не тот».
2. Ассистент: план через DigitalOcean — веб-консоль, **Reset Root Password**, проверка локального `id_rsa` / `config`.
3. FileZilla не коннектится — нужен **SFTP + ключ**, не устаревший пароль.
4. Пользователь сообщил актуальный IP: **`207.154.238.178`** (старый в config мог быть `164.90.168.39`).
5. Обновлён SSH `HostName` на ПК; для FileZilla — хост, порт 22, user `root`, ключ `id_rsa`.
6. Если ключ не принят: в консоли DO добавить строку из локального `id_rsa.pub` в `/root/.ssh/authorized_keys`.
7. Пользователь: «Подключился» — доступ восстановлен.
8. Запрос: сохранить этот чат в GitHub и на будущее направлять в гайд в репозитории.
