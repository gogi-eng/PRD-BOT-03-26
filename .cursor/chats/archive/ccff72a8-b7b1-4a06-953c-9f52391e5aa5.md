## Ассистент

Вы ввели строку cron прямо в терминал, поэтому сервер ответил `0: command not found`.

Эту строку нужно добавлять не в командную строку, а в расписание cron.

Сделайте так:

```bash
crontab -e
```

Откроется редактор. В самый низ добавьте строку, но путь замените на реальный путь к папке бота:

```bash
0 */2 * * * cd /root/PRD-BOT-03-26 && bash scripts/run_trade_context_snapshot.sh
```

Если бот лежит в другой папке, сначала узнайте путь:

```bash
pwd
```

или перейдите в папку бота и выполните:

```bash
pwd
```

После сохранения cron сам будет запускать скрипт каждые 2 часа. Проверить список задач:

```bash
crontab -l
```
