# Финал оформления (все документы)

Обязательно (`universal-document-rules`, `document-structure-toc`):

1. Двойные пробелы — убрать.
2. Пустая строка перед заголовком главы.
3. Заголовки глав — по центру.
4. Титул — как в Инструкции по делопроизводству: гриф справа (≈12,3 см),  
   название по центру, «Минск» внизу; после титула — разрыв.
5. **Содержание кликабельное** — поле Word TOC с `\\h` (Heading 1).
6. Отступ **1,25 см** (кроме заголовков).
7. Длинную должность у подписанта — перенести (**одинарный** интервал внутри должности;  
   **1,5** между подписантами).
8. **Лист согласования** = подписанты, **без** разрыва страницы (сразу после текста), `СОГЛАСОВАНО`.
9. **Лист регистрации изменений** — **отдельная страница**; приложения — с новой.
10. Таблицы: титул 14 / остальные 12; before/after 0.
11. `Разработал:`, примечания, нумерация.
12. **Без маркеров** (`–`, `•`, `-` в начале строк).
13. Подстрочные `(должность)` `(подпись)` `(Ф.И.О.)` — **11–12 пт**.
