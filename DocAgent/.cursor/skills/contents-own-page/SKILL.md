# Содержание → разрыв → глава с верха

Для **всех** документов:

1. Разрыв страницы **перед** «Содержание» / «Оглавление»  
   (титул до этого — только утверждение + название + «Минск»;  
   предисловие — со своей страницы после титула).
2. Разрыв страницы **после** блока содержания — **перед** первой главой текста.
3. Пустые строки перед этой первой главой **убрать** — глава с верха листа.
4. Перед остальными заголовками глав — одна пустая; заголовки по центру.

Код: `separate_contents_onto_own_page`, `format_chapter_headings`,  
`apply_document_structure_rules` (кликабельный TOC).  
Правила: `universal-document-rules.mdc`, `document-structure-toc.mdc`.
