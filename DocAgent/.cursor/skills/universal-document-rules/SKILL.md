# Универсальные правила (все документы)

Применять **всегда**, в конце обработки (`finalize_notes_and_signatories`):

| № | Правило | Код |
|---|---------|-----|
| 1 | Убрать двойные пробелы везде | `collapse_double_spaces_in_document` |
| 2 | Пустая строка перед заголовком главы | `format_chapter_headings` / `ensure_empty_line_before_chapters` |
| 3 | Заголовки глав по центру | `format_chapter_headings` |
| 4 | После Содержания — разрыв; глава с верха | `separate_contents_onto_own_page` |
| 5 | Отступ 1,25 см (кроме заголовков) | `apply_body_first_indents` |
| 6 | Подписанты: СОГЛАСОВАНО, 12 см, перенос должности, 1,5 | `apply_signatory_block_format` |

Не отключать для «unsupported» / приказа / положения.

Подписанты: заголовок **СОГЛАСОВАНО** (заглавными);  
ФИО **без пробела** — `И.И.Иванов`.  
Подробности — `signatories-layout.mdc`, навык `ri-signatories`.
