# Подписанты (все документы)

Правила блока подписантов — **для любого** вида документа.

## Форма (всем)

```
<пустая строка>
Разработал:
Должность<таб 12 см>И.И.Иванов

СОГЛАСОВАНО
Должность<таб 12 см>И.И.Иванов
…
```

1. **Пустая строка** перед `Разработал:`.
2. **`Разработал:`** — всегда (если нет — добавить).
3. После блока разработчика — **пустая строка** перед согласованием.
4. Заголовок согласования — **`СОГЛАСОВАНО`** (заглавными, жирный).
5. Межстрочный интервал блока = **1,5**.
6. **ФИО без пробела** — `И.И.Иванов` (не `И.И. Иванов`); таб **минимум 12 см**.
7. Длинную должность — перенести.
8. Дата — одна строка на 12 см.
