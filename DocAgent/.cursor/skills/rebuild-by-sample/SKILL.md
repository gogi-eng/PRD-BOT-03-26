# Перестройка по образцу (handoff от делопроизводителя)

Когда пользователь просит выполнить задание делопроизводителя или в `DocAgent/handoff/` есть `PROMPT_FOR_CURSOR.txt` / `request_latest.json`:

1. Прочитай `handoff/request_latest.json` и `handoff/PROMPT_FOR_CURSOR.txt`.
2. Исходник и образец — по путям из JSON (DOCX/PDF).
3. Для PDF-сканов: извлеки текст / OCR / рендер страниц.
4. Перестрой документ по **структуре образца**, адаптируя содержание под предприятие исходника (обычно «Минсккоммунтеплосеть»).
5. Сохрани **новым** `.docx`, исходник не затирай.
6. Кратко ответь по-русски: куда сохранён файл и что изменилось.

Не ограничивайся сменой шрифтов — нужна смысловая структура (разделы, права/обязанности, приложения), как в образце.
