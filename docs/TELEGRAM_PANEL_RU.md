# Панель Telegram — шпаргалка для Виктора

Управление ботом **только кнопками**. Команды в чат писать не нужно (кроме `/start` или `/panel`).

## Каждый день

| Кнопка | Зачем |
|--------|--------|
| **▶️ Старт торговли** | Запустить цикл анализа и сделок |
| **⏸ Стоп** | Остановить цикл (позиции на бирже остаются) |
| **📊 Статус** | Баланс, открытые позиции, блокировки риска |
| **📈 Статистика** | Winrate и PnL за сутки |
| **🧪 Лаборатория** | Почему бот **пропустил** сигналы (главное для обучения) |

## Риск и пресеты

| Кнопка | Режим |
|--------|--------|
| **🛡 Консерв** | Меньше сделок, жёстче фильтры |
| **⚖️ Норма** | Сбалансированный режим |
| **🚀 Агресс** | Больше входов, выше риск |
| **🛑 Emergency stop** | Немедленно всё остановить |
| **💰 Сбросить убыток** | Обнулить дневной минус (осторожно!) |

## Песочница AGENT-WORLD

| Кнопка | Значение |
|--------|----------|
| **🔭 Signal-only** | Бот шлёт «вошёл бы», но **не ставит ордер** |
| **⏸ Пауза входов** | Анализ идёт, новые сделки не открываются |

## Защита депозита

| Кнопка | Значение |
|--------|----------|
| **🛡 Ликвидация** | Расстояние до цены ликвидации Bybit по каждой позиции |
| **📖 Справка** | Эта памятка в Telegram |

## Важно

1. На **PROD** и **AGENT-WORLD** должен работать **только один** бот с вашим токеном (иначе Telegram Conflict).
2. API-ключ Bybit: **торговля да**, **вывод нет**.
3. Сначала неделю смотрите **Лабораторию** и **Signal-only**, потом включайте live.
