## Отключение сопровождения ручных сделок

**Цель:** бот ведёт только свои позиции по сигналам AGENT-WORLD и **не трогает** ручные (manual) сделки на том же аккаунте.

Главные настройки в `config.yaml`:

| Параметр | Значение | Смысл |
|----------|----------|--------|
| `positions.adopt_manual` | `false` | Не «подхватывать» ручные позиции |
| `sl_tp_guard.include_manual` | `false` | Не ставить/править SL/TP на manual |
| `manual_auto_close` | `false` | Не автозакрывать ручные |

Сервер AGENT-WORLD:

- Каталог: `/root/AGENT-WORLD`
- systemd unit: `trading_bot_agent_world`

Раньше без правок конфига и деплоя нельзя было переключить режим «ручные» из Telegram — только правка `config.yaml` на сервере.

## Можно ли без деплоя: трейлинг OFF + стоп/пауза?

**Нет.** Это **не замена** `adopt_manual: false`.

- **Трейлинг OFF** — отключает trailing **везде** (и bot, и manual), но SL/TP на manual всё ещё может ставиться, если `adopt_manual=true`.
- **Пауза входов** — бот не открывает новые ордера, но **продолжает вести** уже открытые позиции.
- **Стоп / Emergency** — останавливает **весь** торговый цикл (нет новых сигналов и нет ведения открытых).

Нужный режим для «бот не трогает ручные»:

1. `positions.adopt_manual: false` в конфиге, **или**
2. кнопка Telegram **«🖐 Ручные»** (после деплоя ветки с этой функцией) → **ВЫКЛ**.

## Кнопка Telegram (новое)

- Ветка кода: `25.08.26-AGENT-WORLD`
- Коммит (примерно): `f16431c`
- В Telegram появляется переключатель: **«🖐 Ручные: ВКЛ / ВЫКЛ»**
  - **ВЫКЛ** ≈ не сопровождать manual (аналог adopt_manual off)
  - **ВКЛ** ≈ снова можно подхватывать/вести ручные по политике конфига

Деплой одной командой (пример):

```bash
sudo bash scripts/deploy_agent_world_algo.sh /root/AGENT-WORLD 25.08.26-AGENT-WORLD
```
