## Решения 27–28.07 (актуальный фокус)

### Opposite hold (XAUUSDT flip)

- Проблема: вход BUY -> через ~15 мин opposite SELL -> немедленное закрытие; не хватало «выдержки» и порога уверенности.
- Fix (общий код -> обе ветки):
  - `opposite_signal_policy.py` — `min_position_age_min`, `min_confidence_pct`
  - `orchestrator.py` — hold перед закрытием по opposite
  - `scanner_reversal_sl.py` — возраст позиции
  - тест: `test_opposite_exit_hold_gate.py`
- Песочница после деплоя: hold ~20 мин, confidence >= ~68%.
- Связанный коммит: **`b2db72b`** — hold gate перед opposite exit.

### Ликвидные пары

- Скрипт: `scripts/hourly_liquid_pairs_report.py` (публичный API Bybit, без ключей).
- Отчёты: `data/reports/liquid_pairs_latest.md` + JSON по часам (**не коммитить огромные логи/архивы отчётов**).
- Планировщик: скрипты в `scripts/` + регистрация Windows task (`05c702d`, `a3a25e5`).
- **Каждый час в Telegram** (ПК Task Scheduler + `--telegram`): либо **рекомендуемый сигнал** (символ, LONG/SHORT, вход/SL/TP), либо **«почему без сигнала»** простым языком. Credentials: `TELEGRAM_TOKEN` + `TELEGRAM_CHAT_ID` в `.env` корня проекта (секреты не в git).
