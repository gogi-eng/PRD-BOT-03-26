## 4. Free Claude Code (FCC) + Pi

**FCC** ([free-claude-code](https://github.com/Alishahryar1/free-claude-code)) — локальный прокси на `:8082` для AI бота.

**Pi** — агент для кода в терминале; после установки добавить Node в PATH (`Y` в установщике).

| Компонент | Команда |
|-----------|---------|
| Установка FCC | `curl -fsSL .../install.sh \| sh` |
| Запуск FCC | `fcc-server` или `systemctl start fcc-server` |
| Админка | `http://127.0.0.1:8082/admin` (через SSH-туннель) |
| Pi через FCC | `fcc-pi` |
| Код через FCC | `fcc-claude` |

**Важно:** статья [Habr OpenClaude](https://habr.com/ru/articles/1018234/) — **другой проект**, для бота не нужен.

## 5. Проблемы на сервере (незавершено)

| Проблема | Статус |
|----------|--------|
| `fcc-server: command not found` | FCC не установлен |
| `fcc-server.service` bad unit | Создан с пустым `ExecStart` — удалить и пересоздать после установки |
| SSH `Connection timed out` к `207.154.238.178:22` | Туннель с ПК не работает |
| `ERR_CONNECTION_REFUSED` на `127.0.0.1:8082/admin` | Нет туннеля и/или FCC не запущен на сервере |

**Обход:** настройка FCC через **DigitalOcean → Launch Droplet Console** (браузерный терминал), без SSH с ПК.

**Проверки на сервере:**

```bash
which fcc-server
systemctl status fcc-server
curl -s http://127.0.0.1:8082/health
```
